# CodexBar v0.6.0

用一枚 Windows 托盘状态球查看 Codex 周额度与 5 小时额度。

## 下载与运行

- 下载 **CodexBar.exe**，保存到固定文件夹后直接运行；无需安装。
- 或下载 **CodexBar-v0.6.0-windows.zip**，解压后运行其中的 EXE。
- 需要 Windows 10/11、.NET Framework 4.8，以及已安装并使用 ChatGPT 账户登录的 Codex。
- 程序启动后位于右下角通知区域，右键图标打开“Codex 额度与设置”。

## 功能

- 内球表示周剩余额度，外圈表示 5 小时剩余额度。
- 每分钟同步，显示重置时间，支持低额度提醒和可选开机启动。
- 启动、左键和双击不弹窗；额度与设置集中在右键面板。
- 自动发现当前 Codex 安装，支持更新后重新定位与连接重试。

在线查询失败时会标明本机快照的时间与状态；过期数据不会被当成实时额度。CodexBar 是独立项目，并非 OpenAI 官方客户端。

## 更新与校验

更新前从托盘退出旧版本，再替换 EXE。设置保存在 `%LOCALAPPDATA%\CodexBar`。

可用 PowerShell 检查下载文件的 SHA-256，并与 `SHA256SUMS.txt` 中对应条目比较：

```powershell
Get-FileHash .\CodexBar.exe -Algorithm SHA256
```
